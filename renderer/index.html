随机播放器 5.8.1 指南

这是什么？

这是一款 Windows 本地视频随机播放器（绿色便携版）。它能够扫描您电脑中的文件夹（包括多级子目录），以"不放回抽卡"的形式随机播放视频。数据保存在 EXE 旁的 data 文件夹中，整个文件夹打包压缩即可带走，换电脑解压即用。

第一次使用

点击左侧「创建合集」→ 添加存放视频的文件夹（可添加多个，自动递归子目录）→ 输入合集名称 → 创建合集 → 点击「随机抽取」即可开始播放。
💡 也可以直接把文件夹拖进窗口创建合集。

数据在哪？

所有数据（合集、观看记录、成就、点赞、前缀预设等）保存在 EXE 同目录下的 data 文件夹。想备份/迁移：直接复制整个文件夹（或打包 zip）即可。点顶部绿色「数据目录就绪」可查看具体路径。

快捷键

空格：播放/暂停 ｜ ←/→：快退/快进10秒 ｜ Ctrl+D：随机抽取（播放中随时可用） ｜ Delete：删除当前视频（先弹出确认，弹窗中再按一次即确认删除） ｜ Esc：关闭弹窗

按钮介绍：

随机抽取：从当前合集剩余未看视频中随机抽取播放（播完自动播下一个）
🎬 字幕：切换当前视频的外挂字幕显示；按钮高亮表示字幕开启，左侧“已加载 / 未加载”表示当前视频是否成功匹配字幕
📁 字幕目录：选择独立字幕文件夹，程序只读取该文件夹本层的 `.srt` 文件，并按视频名称（不含扩展名）同名匹配；没有匹配字幕时显示“未加载”
✏️ 命名：修改当前视频文件名，可只改名、只加前缀或两者同时（前缀预设可管理）
🏷️ 标签：为视频打标签（MAX/HIGH/LOW 等，仅记录在存档中，不修改文件名），可管理标签预设
🗑️ 删除：把当前视频文件移入系统回收站（可到 Windows 回收站还原）
📂 路径：在资源管理器中定位当前视频
更新当前合集：重新扫描文件夹，同步新增/删除的视频
补充当前合集：把其他文件夹的视频补充进当前合集（可多选，合并为一个合集）
创建视频合集：选择文件夹创建合集（可多选，自动递归子目录）

常见问题（Q&A）

Q1：EXE 需要安装吗？换电脑怎么迁移？
A：完全绿色免安装。把整个程序文件夹打包复制到新电脑即可，data 文件夹里的数据（合集、记录、成就）全部跟随。

Q2：备份备份的是什么？为什么不包含视频文件？
A：备份的是视频路径、合集名称和观看记录等数据，生成很小的 JSON 文件。视频文件仍保存在原位置。

Q3：如何恢复数据？
A：备份/恢复弹窗 →「恢复」→ 选择 JSON 备份文件 → 确认后数据载入。若备份中的视频目录已失效，点击弹窗内「关联文件夹」重新选择目录即可。

Q4：支持哪些视频格式？
A：可扫描识别 mp4、m4v、webm、ogg、mov、mkv、avi、flv、wmv、ts 等格式。mp4、m4v、webm、ogg、mov 通常可直接播放；其他格式建议转码为 MP4。无法解码或文件损坏时会自动跳过。

Q5：命名（改名/加前缀）会改坏文件吗？
A：不会。扩展名被强制保留，非法字符、重名、系统保留名都会被拦截；改名失败不影响原文件。

Q6：删除的视频还能找回吗？
A：能。删除只是把文件移入 Windows 系统回收站，可到回收站还原或彻底清空。

Q7：我把视频文件移动位置了怎么办？
A：点击「更新当前合集」，系统会重新扫描并移除已失效的视频；若整个文件夹都移动了，请删除合集后重新创建。

Q8：单个文件夹视频太多会卡吗？
A：首次扫描时可能有短暂等待（数千个文件约几秒），扫描完成后正常使用。建议按类型分多个合集。

Q9：观看指数是什么？
A：观看指数综合反映您对视频的喜好程度，计算公式为：指数 = √(播放次数) × (调整后拖拽 × 1 + 点赞 × 0.9)，其中调整后拖拽 = 拖拽次数 / (1 + √文件大小MB)。该数值仅用于内部排序，不直接显示。

Q10：为什么字幕显示“未加载”？
A：请先点击“字幕目录”选择字幕文件夹，再确认 `.srt` 文件与视频名称（不含扩展名）完全相同。程序只查找所选文件夹本层，不会递归子文件夹；字幕开关关闭时仍可能显示“已加载”，因为“已加载”只表示字幕文件已成功读取。
