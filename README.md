# 随机播放器 5.2（桌面版）使用说明

一个免安装、数据随行的 Windows 本地视频随机播放器。以"不放回抽卡"的形式随机播放你电脑里的视频。

---

## 📦 快速开始

1. 解压/复制整个文件夹到任意位置（桌面、U盘、移动硬盘均可）；
2. 双击 `随机播放器.exe`；
3. 点左侧「创建合集」→「+ 添加目录」选择视频文件夹（可多个）→ 起名 → 创建；
4. 点「随机抽取」开始播放（播完自动播下一个）。

> 也可以直接把文件夹拖进窗口创建合集。

## 🗂️ 数据随行（重点）

- 所有数据（合集、观看记录、点赞、成就、前缀预设）保存在 **EXE 同目录的 `data` 文件夹**；
- 换电脑 / 备份 / 迁移：**直接复制整个文件夹（或打包成 zip）即可**，数据全部跟随；
- **更新版本不丢存档**：把新版本解压到与旧版本**同级**的文件夹（如旧的 `随机播放器4.0` 旁边新建 `随机播放器4.1`），首次启动会自动检测到旧存档并弹窗询问是否导入；也可直接解压覆盖到原目录（data 保留）；
- 顶部绿色「数据目录就绪」可点击查看具体路径；
- 删除 `data` 文件夹 = 恢复出厂（程序重新生成空数据）。

## 🎬 播放器操作

| 按键/操作 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 10 秒 |
| **Ctrl + D** | **随机抽取**（全局生效：播放中、视频聚焦、任意状态都可用） |
| **Delete** | **删除当前视频**：先弹出确认弹窗；弹窗中再按一次即确认删除（输入框打字时仍为删字符） |
| Esc | 关闭弹窗 |
| 视频底部区域 | 悬停显示控制条（进度、音量、全屏） |
| 双击视频 | 全屏 / 退出全屏 |

支持格式：mp4 / webm / ogg / mov 可直接播放；mkv / avi / flv / wmv / ts 等不支持，请转码为 MP4（转码工具：格式工厂等）。

## ✏️ 文件管理（当前视频操作栏）

播放任意视频后，播放器下方出现操作栏：

- **✏️ 重命名/前缀**：修改当前视频文件名——可只改名、只加前缀、或两者同时（前缀预设可管理）；
- **🏷️ 加标签**：为视频打标签（MAX/HIGH/LOW 等，可管理预设）。标签**只记录在存档中、不修改文件名**，点击标签卡片高亮即添加，再点取消；
- **🗑️ 删除**：把该视频文件移入 **Windows 系统回收站**（可去回收站还原或彻底清空，不会直接销毁）。程序会先释放播放器占用再删除，若系统回收站不可用会提示是否永久删除；
- **📂 所在文件夹**：在资源管理器中定位该文件；
- **创建标签合集**：勾选一个或多个标签创建合集，自动聚合所有带这些标签的视频——**动态跟随**（之后新打标签的视频自动进入，取消标签自动移出），观看记录与视频合集共享，只提供重置与删除。

> 重命名/加前缀后正在播放的视频会**保持进度继续播放**，观看记录、点赞、统计均不受影响。

## 💾 备份与恢复

- **备份**：导出当前全部数据为 JSON 文件（默认存到 `data\backups`）；
- **恢复**：选择 JSON 备份导入，覆盖前有确认提示，**且会自动备份当前数据到 `data\backups`**（误操作可找回）；
- **数据初始化**（右上角"初始化"按钮）：清空前也会自动备份；
- **刷新合集保护**：扫描到 0 个视频时不会直接清空列表（可能只是文件夹暂时不可访问），需确认才覆盖；
- **旧版网页版（3.1）备份**：格式兼容，导入后点击「关联文件夹」重新选择视频目录即可匹配观看记录；
- 备份不包含视频文件本身（视频仍在原位置）。

## ⚙️ 其他功能

- ⚙️ 策略变更：默认 / 点赞加权 / 短片优先 / 长片优先；
- 👍/👎 点赞点踩、📋 浏览历史、📊 排行统计与观影报告（可导出图片）、🏆 成就系统；
- 合集标签可拖拽排序；补充 / 更新 / 重置 / 删除合集；数据初始化（清空全部数据）。
- **补充当前合集**：选中合集中追加其他文件夹（可连续多选），视频合并播放；**更新当前合集**：重新扫描文件夹同步增减。

## ⚠️ 注意事项

- 首次运行若出现 Windows SmartScreen 提示：点「更多信息」→「仍要运行」（程序未签名所致，属正常现象）；
- 杀毒软件可能误报，添加信任即可；本程序纯本地运行，不联网、不上传任何数据；
- 请勿把 EXE 放到 Program Files 等受保护目录（数据写入可能被系统拒绝）；
- 程序单实例运行，重复打开会聚焦已有窗口。

## 🛠️ 技术信息

- 开发框架：Electron（Chromium 内核）；
- 数据文件：`data/data.json`（版本 12，原子写入 + 自动 `.bak` 轮换）；
- 版本：5.2（基于 随机播放器 3.1 网页版移植）。
