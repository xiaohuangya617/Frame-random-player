# 随机播放器 5.8.1

## 📦 快速开始

1. 解压/复制整个文件夹到任意位置（桌面、U盘、移动硬盘均可）；
2. 双击 `随机播放器.exe`；
3. 点左侧「创建视频合集」→「+ 添加目录」选择视频文件夹（可多个）→ 起名 → 创建；
4. 点「随机抽取」开始播放（播完自动播下一个）。

> 也可以直接把文件夹拖进窗口创建合集。

## 🗂️ 数据随行（重点）

- 所有数据（合集、观看记录、点赞、成就、前缀预设）保存在 **EXE 同目录的 `data` 文件夹**；
- `data.json` 损坏时会优先从健康的 `data.json.bak` 恢复并提示；主存档与备用存档都损坏时进入空数据保护模式，不会静默覆盖旧文件；
- 换电脑 / 备份 / 迁移：**直接复制整个文件夹（或打包成 zip）即可**，数据全部跟随；
- **更新版本不丢存档**：把新版本解压到与旧版本**同级**的文件夹（如旧的 `随机播放器4.0` 旁边新建 `随机播放器4.1`），首次启动会自动检测到旧存档并弹窗询问是否导入；如当前 `data` 目录仍有备用存档或历史备份，导入前会把整个目录保留为同级 `data-before-import-*` 恢复副本；也可直接解压覆盖到原目录（data 保留）；
- 顶部绿色「数据目录就绪」可点击查看具体路径；
- 删除 `data` 文件夹 = 恢复出厂（程序重新生成空数据）。

## 🎬 播放器操作

| 按键/操作 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 10 秒 |
| **Ctrl + D** | **随机抽取**（全局生效：播放中、视频聚焦、任意状态都可用） |
| **Delete** | **删除当前视频**：先弹出确认弹窗；弹窗中再按一次即确认删除（输入框打字时仍为删字符） |
| Esc | 关闭弹窗 |
| 视频底部区域 | 悬停显示控制条（进度、音量、全屏） |
| 视频上半区单击 | 播放 / 暂停 |
| 视频上半区双击 | 全屏 / 退出全屏 |
| 视频下半区单击/双击 | 不触发暂停或全屏；底部控制栏仍可操作 |

可扫描识别 mp4 / m4v / webm / ogg / mov / mkv / avi / flv / wmv / ts 等主流视频容器。mp4 / m4v / webm / ogg / mov 通常可直接播放；其他格式取决于编码兼容性，建议转码为 MP4。无法解码或文件损坏时会自动跳过，不计入观看。

## ⚠️ 已知限制与常见缺点

- **扫描到不代表一定能播放**：程序可以识别上述视频扩展名，但实际播放仍取决于视频内部编码。H.265/HEVC、AV1、部分老旧 AVI/WMV、特殊音轨或损坏文件可能无法由当前 Chromium 播放；播放失败时会自动跳过。
- **当前版本使用 Chromium 原生播放**：尚未接入 FFmpeg 转封装/转码，因此遇到编码不兼容的视频，需要先用外部工具转为常见的 H.264 + AAC MP4。FFmpeg 播放兼容计划留给后续版本。
- **外挂字幕只支持 SRT**：字幕必须放在单独选择的字幕目录中，并与视频文件名（不含扩展名）完全相同；只查找该目录本层，不递归子目录，不支持 ASS/SSA 等其他字幕格式，也没有时间偏移和多语言切换。
- **字幕功能不负责生成或翻译**：当前没有 AI 字幕识别、翻译和接口配置功能，需要先用外部工具生成 SRT 文件。
- **目录暂时不可访问时需要手动处理**：移动硬盘断开、网络目录不可用或文件夹正在写入时，合集可能显示失效；重新连接后可使用“更新当前合集”或“关联文件夹”恢复。
- **本地单机工具**：数据保存在本地 `data` 文件夹，不提供云同步、多设备同步和多人协作。
- **窗口尺寸不记忆**：程序每次按固定的初始窗口尺寸启动，需要手动调整显示大小。

## ✏️ 文件管理（当前视频操作栏）

播放任意视频后，播放器下方出现操作栏：

- **🎬 字幕**：切换字幕显示；按钮高亮表示开启，旁边显示当前字幕“已加载 / 未加载”；
- **📁 字幕目录**：选择只读取本层 `.srt` 文件的独立字幕文件夹；
- **✏️ 命名**：修改当前视频文件名——可只改名、只加前缀、或两者同时（前缀预设可管理）；
- **🏷️ 标签**：为视频打标签（MAX/HIGH/LOW 等，可管理预设）。标签**只记录在存档中、不修改文件名**，点击标签卡片高亮即添加，再点取消；
- **📂 路径**：在资源管理器中定位该文件；
- **🗑️ 删除**：把该视频文件移入 **Windows 系统回收站**（可去回收站还原或彻底清空，不会直接销毁）。程序会先释放播放器占用再删除，若系统回收站不可用会提示是否永久删除；
- **创建标签合集**：勾选一个或多个标签创建合集，自动聚合所有带这些标签的视频——**动态跟随**（之后新打标签的视频自动进入，取消标签自动移出），观看记录与视频合集共享，只提供重置与删除。

> 重命名/加前缀后正在播放的视频会**保持进度继续播放**，观看记录、点赞、统计均不受影响。

## 💾 备份与恢复

- **备份**：导出当前全部数据为 JSON 文件（默认存到 `data\backups`）；
- **恢复**：选择 JSON 备份导入，覆盖前有确认提示，**且会自动备份当前数据到 `data\backups`**（误操作可找回）；
- **数据初始化**（右上角“🔄 初始化”按钮）：清空前也会自动备份；
- **刷新合集保护**：扫描到 0 个视频时不会直接清空列表（可能只是文件夹暂时不可访问），需确认才覆盖；
- **旧版网页版（3.1）备份**：格式兼容，导入后点击「关联文件夹」重新选择视频目录即可匹配观看记录；
- 备份不包含视频文件本身（视频仍在原位置）。
